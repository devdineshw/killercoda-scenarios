Download the WSO2 APIM binary.

> **_NOTE:_** You could download the WSO2 product binary files from the official WSO2 website product download page.

- Use the following command to download the WSO2 API Manager binary file for this lab.

    `wget -O wso2am-4.5.0.zip https://github.com/wso2/product-apim/releases/download/v4.5.0/wso2am-4.5.0.zip`{{execute}}

- Create a directory for the API Manager installation

    `mkdir apim1`{{execute}}

- Extract the WSO2 APIM binary to the new folder

    `unzip wso2am-4.5.0.zip -d apim1/`{{execute}}
