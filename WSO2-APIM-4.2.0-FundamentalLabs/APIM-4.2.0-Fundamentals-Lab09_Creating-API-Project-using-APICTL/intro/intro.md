This scenario shows how to 
 - configure the APICTL 
 - create and publish an API Project

Please note that, a given APICTL tool version is tightly coupled with a API Manager produvt version. APICTL tool campatible with API Manager 4.2.0 might not work with another API Manager version. Make sure to use the compatible APICTL tool with your API Manager version.
