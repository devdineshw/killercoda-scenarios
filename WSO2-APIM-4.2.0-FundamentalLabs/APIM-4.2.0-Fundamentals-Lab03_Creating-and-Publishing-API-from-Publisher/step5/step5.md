- Login to the publisher portal with a user who has 'publisher' permissions.

- Select the API to be published. 'PizzaShack' API in this case.

- Publish the API

    - Option 1: Click the 'Publish' button from the API overview page.

    - Option 2: Go to the 'Publish' > 'Lifecycle' page from the left menu, then click 'Publish' button

    Once this step is compleated, API is ready to invoke.
