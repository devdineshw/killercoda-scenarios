You can mark an API to be deployed to selected API Gateway environment/s via the Publisher Portal. This operation will create a revision of the API in order to deploy it.

- Select 'Deployments' tab under 'Deploy'

- Select the prefered gateway environment to deploy the API. Only 'Default' Gateway environment will be available in a fresh API manager setup.
- Click 'Deploy' button

    A new revision will be created with the current state of the API. 
    
As you can see at the top of the page, API is still in the 'CREATED' state. We need to promote the API to 'PUBLISHED' state to push the API to above selected gateway runtime environment/s.
