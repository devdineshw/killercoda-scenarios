This lab will guide you to expose a WebSocket service through the WSO2 API Manager. Follow the instructions in this tutorial to design and publish the API, and thereafter invoke the WebSocket API using the wscat client.

In this lab, following pre-requisites are getting configured in the background.
  
  - Node JS based websocket service 
    
    Source: https://github.com/wso2/samples-apim/tree/master/streaming-api-backends/websocket-backend
    
  - NodeJS runtime and dependancies
  - WSCAT client tool
    

> **_NOTE:_** Please wait until the playground is ready to start the scenario. Usually it will take around 5 mins to load.
