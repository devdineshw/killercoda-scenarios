Download the WSO2 APIM and IS binary files.

> **_NOTE:_** [Optional] You could download the WSO2 product binary files from the WSO2 website as well.

#### API Manager 4.2.0

- Use the following command to download the WSO2 API Manager binary file.

  `wget -O wso2am-4.2.0.zip https://github.com/devdineshw/resources/raw/main/binaries/WSO2/APIM/4.2.0/wso2am-4.2.0.zip?download=true`{{execute}}

- Create a directory for the API Manager installation

  `mkdir apim1`{{execute}}

- Extract the WSO2 APIM binary to the new folder

  `unzip wso2am-4.2.0.zip -d apim1/`{{execute}}

#### Identity Server 6.1.0

- Use the following command to download the WSO2 Identity Server binary file.

  `wget -O wso2is-6.1.0.zip https://github.com/devdineshw/resources/raw/main/binaries/WSO2/IS/6.1.0/wso2is-6.1.0.zip?download=true`{{execute}}

- Create a directory for the API Manager installation

  `mkdir is1`{{execute}}

- Extract the WSO2 APIM binary to the new folder

  `unzip wso2is-6.1.0.zip -d is1/`{{execute}}
