Download the WSO2 APIM binary.
NOTE: You could download the WSO2 product binary files from the WSO2 website.

Please go to the following link and grab the download link.

https://fastupload.io/EIs3WRpdU52v/Ng0daj3OonJ6iN2/k0embL0lazVb4/wso2am-4.2.0.zip


- Use the following command to download the WSO2 API Manager binary file. Replace the <DOWNLOAD_LINK> with the URL you obtained

`wget -O wso2am-4.2.0.zip --user-agent=Mozilla/5.0 <DOWNLOAD_LINK>`{{copy}}

- Create a directory for the API Manager installation

`mkdir apim1`{{execute}}

- Extract the WSO2 APIM binary to the new folder

`unzip wso2am-4.2.0.zip -d apim1/`{{execute}}
