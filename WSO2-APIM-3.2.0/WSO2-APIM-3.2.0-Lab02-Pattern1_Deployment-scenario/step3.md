Download the WSO2 APIM binary.

1) Use the following command to download the file. Replace <USERNAME> with your WSO2 account username (email address)

`wget --user <USERNAME> --ask-password https://product-dist.wso2.com/products/api-manager/3.2.0/eula/wso2am-3.2.0.zip`

2) Create a directory for the first APIM instance

`mkdir apim1`{{execute}}

3) Extract the WSO2 APIM binary to the new folder

`unzip wso2am-3.2.0.zip -d apim1/`{{execute}}
